# GAZEL_BOT — бот грузоперевозок на Газели

Telegram-бот, в котором клиент за минуту считает стоимость перевозки по адресам и оформляет заказ.
Плюс отдельный Telegram-канал с новостями, куда админ публикует посты прямо из бота.

## Как это работает

**Клиент**
1. `/start` → делится номером телефона кнопкой (Telegram сам подтверждает, что номер принадлежит человеку, SMS не нужны).
2. Главное меню:
   - 🚚 **Заказать перевозку** — вводит адрес «откуда» и «куда» (текстом, геолокацией или из недавних) →
     бот считает километраж по дорогам и показывает сумму → «Оформить заказ».
   - 📍 **Мои адреса** — адреса из прошлых заказов (подставляются при новом заказе, можно удалять).
   - 📋 **Мои заказы** — история и статусы.
   - 📰 **Новости** — ссылка на канал.
   - 💰 **Тарифы**.

**Админ**
- Новая заявка приходит в чат админов с телефоном клиента и кнопками «Принять / Отклонить».
  Клиенту приходит уведомление о решении.
- `/post Текст` — опубликовать новость в канал.
  Или подготовить пост (фото, видео, форматирование) и ответить на него командой `/post`.

**Расчёт цены:** `подача + км × цена за км`, но не меньше минимального заказа, округление вверх до 10 ₽.
Всё задаётся в `.env`.

**Карты:** бесплатные сервисы OpenStreetMap — Nominatim (поиск адреса) и OSRM (маршрут по дорогам).
Если сервис маршрутов не ответил, расстояние оценивается по прямой × 1,3 и помечается как приблизительное.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Создайте канал, добавьте бота в канал **администратором** (право публиковать сообщения).
3. Узнайте свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)) и **нажмите /start у своего бота** —
   иначе он не сможет писать вам заявки.
4. Настройте и запустите (нужен Python 3.11+):

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN, ADMIN_IDS, CHANNEL_ID, CHANNEL_URL
python -m bot
```

Чтобы заявки приходили не в личку, а в группу диспетчеров: добавьте бота в группу и укажите её ID в `ADMIN_CHAT_ID`.

## Структура

```
bot/
  __main__.py        запуск
  config.py          настройки из .env
  db.py              SQLite: пользователи, адреса, заказы
  keyboards.py       кнопки
  texts.py           форматирование сообщений
  handlers/
    start.py         /start и регистрация по телефону
    order.py         оформление заказа (адреса → расчёт → подтверждение)
    menu.py          мои адреса, мои заказы, новости, тарифы
    admin.py         /post в канал, принятие/отклонение заявок
    fallback.py      всё непонятое
  services/
    geo.py           адрес → координаты, расстояние по дорогам
    pricing.py       расчёт стоимости
    notify.py        уведомление админов о заявке
tests/               pytest, включая сквозной сценарий заказа без сети
```

Тесты и линтер: `pip install -r requirements-dev.txt && pytest && ruff check .`
